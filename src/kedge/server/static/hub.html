Workbooks

Everything kedge has been pointed at, most recently used first. Status is read from disk every time this page loads, so a notebook or a workbook you have moved or deleted shows as missing rather than as a row that fails when you click it.

You can also drag a workbook anywhere onto this page.

Drop the workbook

It is copied into ~/.kedge/dropped and registered from there. A dropped file arrives as bytes with no path, and a workbook with no path cannot be re-analysed or named in a plan — so kedge gives it one. Browsing is the better route.
